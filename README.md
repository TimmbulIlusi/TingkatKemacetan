# Sistem Fuzzifikasi Tingkat Kemacetan

Aplikasi Streamlit untuk menentukan tingkat kemacetan berdasarkan jumlah kendaraan menggunakan Logika Fuzzy.

## Input

Jumlah kendaraan:

0 - 1000 kendaraan

## Output

- Lancar
- Padat
- Macet

## Instalasi

```bash
pip install -r requirements.txt
```

## Menjalankan

```bash
streamlit run app.py
```

## Teknologi

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
